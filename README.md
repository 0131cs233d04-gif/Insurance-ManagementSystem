Insurance Management System

A full-stack Insurance Management System developed using Spring Boot, React.js, and PostgreSQL. The application allows users to manage insurance policies, customer profiles, premium payments, claims, and provides an admin dashboard for policy management.


Features

- User Registration & Login
- Secure Authentication
- Customer Profile Management
- Insurance Policy Management
- Premium Payment Tracking
- Claim Request Management
- Admin Dashboard
- REST API Integration
- PostgreSQL Database


Tech Stack

Backend

- Spring Boot
- Spring Security
